# Design Log — Leather Shop

Every design artifact published for review, newest first, so a design
made in one session is still visible in the next. See the "Ask before
designing" rule in [CLAUDE.md](../CLAUDE.md) — before adding to this list,
the details and creative direction should already have been discussed with
the user.

- **2026-07-08 — Homepage v2, "Editorial Filipino"**
  [artifact](https://claude.ai/code/artifact/d6c1cb42-5fb9-4204-89bb-8238aa6ebbda)
  Rework of the homepage after a vibe brief: luxurious-editorial,
  approachable (not high-brow), white + light-brown palette, parchment/
  linen textures, native Filipino touches. Fraunces (display, incl.
  italic) + Work Sans (body/UI) type pairing. Category panels use
  generative canvas textures standing in for photography — solihiya
  rattan weave (bags), piña/linen weave (wallets), narra wood grain
  (belts), capiz shell panes (accessories) — instead of icons or stock
  photos. Supersedes the "Atelier Ledger" concept below.

- **2026-07-08 — Homepage, "Atelier Ledger" (superseded)**
  [artifact](https://claude.ai/code/artifact/fc3a95e4-786e-4f8e-aa29-dc66e7494b52)
  Homepage styled like a leatherworker's grading card/spec sheet: a
  generative leather-grain canvas texture and animated saddle-stitch line
  in the hero (no stock photography — none exists yet per PRD §1), an IBM
  Plex serif/sans/mono type system, and a cognac/brass/loden palette.
  Copy pulled from PRD §5–6 (categories, ₱150 Metro Manila delivery,
  ready-to-ship vs. made-to-order). Built before the "ask before designing"
  rule existed — no vibe brief was collected up front. Replaced by the
  entry above after the user asked for a different direction.
